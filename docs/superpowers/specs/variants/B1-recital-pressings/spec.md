# B1 — Recital Pressings
**Bridge: Formal-Led with Vinyl Accent**

## Concept

B1 holds A1's centered, symmetric, proscenium-spotlight grammar as the dominant structural frame — and grafts A4's pressed-record vocabulary onto it as the accent layer. The page reads as a classical recital site first; the vinyl presence is refinement, not decoration.

## Structural Logic

**Hero:** A1 untouched — centered JACQUES, follow-spot cone from above, stage-apron hairline rule, "Begin listening" CTA. A single miniature vinyl-disc emblem (inline, small, amber-ringed) joins the discipline line beneath the rule — the record as imprimatur rather than motif.

**Library / Programme:** A1's centered frosted-glass concert-program container becomes a refined grid of "Pressing" tiles instead of typeset rows. Each pressing tile is portrait-format, frosted, carrying a subtle vinyl-disc motif (upper-right quadrant), catalog number, italic title, genre badge — but laid out in a formal centered grid (2×2 at `max-width: 960px`, centered within the column), preserving A1's symmetry. The tile grid replaces the program list; the program header ("An Evening with Jacques") and footer note are retained above/below the grid.

**About:** A1's centered single-panel frosted glass, centered bio, centered eyebrow/heading — unchanged structurally. A ghosted vinyl disc decorates the far right edge of the panel (A4 accent), position: absolute, clipped.

**Live:** A1's centered frosted live-panel with date/venue rows — unchanged.

**Player bar:** A1's formal 68px bar gains one A4 accent — a miniature turntable disc (spinning when visible) + tonearm, inset left of the track-info column. Controls, progress, waveform: A1 inherited.

## Palette / Typographic Rules

Identical to A1: `--bg-deep: #0f0805`, amber `#c8893a / #e8b060`, chocolate glass, Georgia serif for headings/display, system-ui for labels. No net-fetched resources. Static renders beautifully; animations are progressive enhancement.
